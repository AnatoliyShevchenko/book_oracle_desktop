## 1. Что это

Book Oracle помогает решить, какую книгу читать следующей. Пользователь ведёт список книг в Google Таблице. Приложение раскладывает непрочитанные книги рубашкой вверх. Пользователь по одной открывает карты — открытая карта **выбывает**. Когда остаётся одна карта, она и есть выбор: её показываем крупно на весь экран.

Никаких периодов, «книг месяца» и т. п. — это просто «что сейчас взять почитать».

## 2. Платформа и стек

- Flutter (stable, последняя), **только Windows desktop**, Windows 10 и новее.
- Язык интерфейса — русский. Все строки вынести в одно место (`lib/l10n/strings_ru.dart` или ARB), чтобы потом добавить английский.
- Рекомендуемые пакеты (можно заменить равноценными, но обоснуй):
  - `window_manager` — своя рамка окна, размеры, сплэш-окно;
  - `flutter_riverpod` — состояние;
  - `http` — загрузка CSV;
  - `csv` — парсинг;
  - `path_provider` — папка приложения для кэша и своего фона;
  - `shared_preferences` — настройки;
  - `file_picker` — выбор своего фонового изображения;
  - `url_launcher` — ссылка «Как открыть доступ».
- Шрифты **вшить в assets** (приложение должно выглядеть одинаково без интернета): Unbounded, Onest, Cormorant Garamond, Manrope, Old Standard TT, Prata, Yeseva One. Все под OFL, брать с fonts.google.com. Нужны начертания с кириллицей; веса: Unbounded 500/600/700, Onest 400/500/600/700, Cormorant Garamond 500/600/700, Manrope 400–700, Old Standard TT 400/700, Prata 400, Yeseva One 400.

## 5. Данные: Google Таблица

### 5.1 Ссылка
- Пользователь вставляет ссылку вида `https://docs.google.com/spreadsheets/d/<ID>/edit#gid=<GID>`.
- Извлечь `ID` (regexp `/spreadsheets/d/([a-zA-Z0-9-_]+)`) и `gid` (из `#gid=` или `?gid=`, по умолчанию `0`).
- Не похоже на ссылку на таблицу → ошибка «Это не ссылка на Google Таблицу» (состояние `format`).

### 5.2 Загрузка
- CSV: `https://docs.google.com/spreadsheets/d/<ID>/export?format=csv&gid=<GID>`.
- Таймаут 8 с.
- Если ответ не 200, **или** редирект на `accounts.google.com`, **или** пришёл HTML вместо CSV → «Нет доступа к таблице» (`access`). Подсказка: «Настройки доступа → Все, у кого есть ссылка → Читатель».
- Ошибка сети/таймаут → офлайн-логика (раздел 9).
- **Выбор листа** (best-effort): попробовать получить список вкладок, например разобрав `https://docs.google.com/spreadsheets/d/<ID>/htmlview`. Не получилось — выпадающий список «Лист» не показываем и работаем с `gid` из ссылки. Не блокировать этим MVP.

### 5.3 Столбцы — обязательные
Первая строка — заголовки. Сравнение без учёта регистра и пробелов по краям. **Все три столбца обязательны**, порядок любой, лишние столбцы игнорируются:

| Смысл | Допустимые заголовки |
|---|---|
| Название | `title` или `название` |
| Автор | `author` или `автор` |
| Прочитано | `read` или `прочитано` |

- Нет хотя бы одного → ошибка `columns`: «Не найден столбец «прочитано» (read)» + «Нашли: название, автор…». Если не хватает нескольких, перечислить все.
- Строки с пустым названием пропускаем.
- **Прочитано = истина**, если ячейка непустая (после trim). Пустая ячейка — не прочитано, книга идёт в колоду. Столбец работает как галочка: подойдёт любая пометка — `да`, `✓`, дата, оценка, заметка. Оборотная сторона: `нет` и `0` тоже считаются пометкой и убирают книгу из колоды.
  <br>*Уточнено заказчиком после первой версии; раньше признавался только фиксированный список значений.*
- В колоду идут только непрочитанные. Счётчики: всего строк с названием, в колоде, прочитано.

### 5.4 Количество
- В колоде от **2 до 60** карт.
- Меньше 2 непрочитанных → сообщение на экране расклада: «В таблице меньше двух непрочитанных книг» с кнопками «Обновить» и «Открыть таблицу».
- Больше 60 → **открытый вопрос, уточнить у заказчика.** По умолчанию в каждом раскладе брать случайные 60, в панели писать «В раскладе 60 из N».

### 5.5 Цвет лицевой стороны карты
Цвета из таблицы не берём. Пара «фон / текст» выбирается детерминированно: `autoCardColors[hash(title) % 24]` из `design_tokens.json`. Хэш — стабильный (например FNV-1a по UTF-8), чтобы у книги всегда был один цвет.

## 6. Кэш и настройки

- После каждой успешной загрузки сохранять в `getApplicationSupportDirectory()/cache.json`: ссылку, ID, gid, название таблицы/листа (если известно), список книг (title, author, read) и время загрузки.

- Своё фоновое изображение копировать в папку приложения, не ссылаться на исходный путь.

### 7.1 Сплэш (560×340)
Фон `bg`, мягкое радиальное свечение `glow` по центру. Композиция по центру:

### 7.3 Расклад (главный экран)
Под заголовком окна — тело с отступами `pad/2` сверху и `pad` по бокам и снизу. Слева стол с картами, справа панель шириной `panel` (ступени — раздел 8).

**Стол:**
- Сетка карт по центру свободной области (алгоритм — раздел 8).
- Под сеткой строка высотой 28: слева «Кликните по карте — она выбывает. Последняя оставшаяся — выбор.», справа подсказки клавиш `Пробел` случайная · `R` перетасовать · `F11` весь экран (чипы клавиш с толстой нижней границей).

**Карта** (пропорция 1 : 1.4, скругление 10, тень колоды):
- **Закрыта:** рубашка колоды. Hover — подъём на 5 px.
- **Открытие = выбывание:** поворот вокруг Y на 180°, 0.7 с, кривая `(0.3, 0.8, 0.25, 1)`. На лицевой стороне через 0.45 с включается фильтр grayscale 0.8 + brightness 0.8, внизу плашка «ВЫБЫЛА» (чёрная 72%, 10 px, разрядка 0.14em).
- **Лицо:** фон и текст из авто-палитры; внутренняя рамка 1 px (цвет текста, 45%) с отступом 5; название шрифтом display колоды (10% ширины карты, 9–24 px); орнамент — линия, ромб, линия; автор капсом (6.2% ширины, 8–14 px).
- **Мелкая карта** (ширина меньше 78): только название (13% ширины), без орнамента и автора; плашка «ВЫБЫЛА» 8 px.
- **Последняя оставшаяся:** обводка 2 px `accent` + свечение `accentGlow`, «дыхание» (scale 1 → 1.05 → 1, 1.4 с, по кругу). Клик по ней не работает.
- Когда остаётся одна карта — через 1.1 с запускается показ выбора.
- **Раздача** (старт и после «Перетасовать»): карты влетают сверху (−40 px, поворот ±6°, scale 0.85 → 1), 0.55 с. При перетасовке сначала все карты «собираются» (scale 0.8, прозрачность → 0, 0.7 с), затем новый случайный порядок и раздача.

**Показ выбора** (если в настройках включён «Показывать выбор на весь экран»; иначе только подсветка карты и панель):
- Оверлей на всё тело окна (без заголовка), фон `scrim`, появление 0.5 с.
- Сверху «ОРАКУЛ ОТВЕТИЛ» (13 px, `accent`, разрядка 0.28em) и «Выбор сделан» (display, 36 px).
- Большая карта высотой 50% окна: влетает снизу (scale 0.28 → 1, 0.8 с), в 1.2 с переворачивается рубашкой к лицу (1 с). Лицо: двойная рамка, название (7.5% высоты карты), орнамент, автор.
- За картой медленно вращаются лучи (24 луча, толщина 1/2 через один, прозрачность 0.22/0.45, круг r=330): появляются в 1.3 с, полный оборот за 60 с.
- В 2.2 с — кнопки «К раскладу» (контурная) и «Новый расклад» (основная).

**Панель** (`surface`, скругление 16, рамка `line`, внутренний отступ 1.6em, базовый размер шрифта по ступени):
1. Надзаголовок «СПИСОК», название таблицы (display, 1.75em; если названия нет — «Что почитать»).
2. Источник: иконка таблицы, «Google Таблица · сегодня, 12:40» (относительная дата), кнопка-иконка «Обновить» 36×36.
3. Инфо-строка (если есть прочитанные): «В таблице 30 · прочитанные (6) в колоду не попали».
4. Плашки сети — раздел 9 (заменяют пункт 2 в офлайне).
5. Разделитель.
6. Счётчик «Осталось **17** из 24» (число display 2.6em `accent`) + полоса прогресса 6 px (выбыло / (N−1)). После выбора вместо счётчика — блок «ВЫБОР»: цветной корешок 46×64, название, автор.
7. «ВЫБЫЛИ · N» и журнал: новые сверху, строка = цветной корешок 10×14, название (в одну строку с многоточием), порядковый номер. Список прокручивается. Пустое состояние: «Пока никто. Откройте любую карту или нажмите «Случайная».»

**Клавиатура:** `Пробел` — открыть случайную закрытую карту; `R` — перетасовать; `F11` — полноэкранный режим; `Esc` — закрыть показ выбора / выйти из полного экрана; `Tab`/`Enter` — фокус по картам и открытие.

### 8.2 Сетка карт
Пересчитывать при изменении размера окна и количества карт (`LayoutBuilder`):

```dart
// aw, ah — свободная область стола; n — карт в колоде; R = 1.4
final gap = n <= 24 ? tier.gap : n <= 40 ? (tier.gap * 0.7).round() : (tier.gap * 0.5).round();
var bestCols = 1; var bestW = 0.0;
for (var cols = 1; cols <= n; cols++) {
  final rows = (n / cols).ceil();
  final w = min((aw - gap * (cols - 1)) / cols, ((ah - gap * (rows - 1)) / rows) / R);
  if (w > bestW) { bestW = w; bestCols = cols; }
}
final cardW = min(bestW, 260).floorToDouble();
final cardH = (cardW * R).floorToDouble();
```

где `aw = width − 3·pad − panel`, `ah = height − 36 − pad/2 − pad − 44` (44 = строка подсказок + отступ). Сетку центрировать по обеим осям; неполный последний ряд — по центру.

Проверочные значения (n = 24): 1280×720 → 8 столбцов, карта ~108×152; 1536×864 → 8 столбцов, ~129×181; 2560×1440 → 8 столбцов, ~232×325.

## 9. Сеть и офлайн

- При старте (если `refreshOnStart`) грузим таблицу. Ошибка сети + есть кэш (+ `useCacheOffline`) → работаем с кэшем в **офлайн-режиме**.
- **Офлайн-режим:**
  - в заголовке окна чип «Офлайн» (иконка wifi со слэшем, фон `accentSoft`, текст `accent`, 12 px);
  - в панели вместо строки источника плашка (фон `accentSoft`, рамка `line2`, скругление 12): иконка, **«Нет интернета»**, «Показываем сохранённый список от <дата, время>. Расклад работает как обычно.», кнопка «Проверить снова» (маленькая контурная; при проверке — спиннер и «Проверяем…»);
  - в фоне повторяем попытку раз в 60 с.
- **Связь вернулась** (после «Проверить снова» или фоновой попытки):
  - список перезагружается;
  - плашка «Связь восстановлена» (фон `ok` 12%, рамка `ok` 40%, иконка-галочка): «Список обновлён из таблицы. Изменений нет — текущий расклад сохранён.» Если книги поменялись: «Список изменился: +2, −1. Новый список будет в следующем раскладе»;
  - плашка сама исчезает через 4 с, есть крестик «Скрыть»; чип «Офлайн» пропадает;
  - **текущий расклад не сбрасывается** — новые данные применяются со следующего «Перетасовать» / «Новый расклад».

## 10. Темы (колоды) и фоны

- Каждая колода = `ThemeExtension<DeckTheme>`. Цвета, шрифты display/body и рубашка — из `design_tokens.json`. `ThemeData` строить из колоды (`brightness` из `dark`).
- **Рубашки:**
  - `images` — картинки по очереди (карта i → `files[i % len]`), `BoxFit.cover`;
  - `pattern` — рисовать `CustomPainter`: базовый цвет; для графита и бумаги — две серии диагональных линий 1 px (±45°) с шагом `step`; для сада — точки 1.2 px в сетке 11 px. Поверх — рамка 1.5 px с отступом 7% и скруглением 6, в центре эмблема: ромб (квадрат 26% ширины, повёрнутый на 45°, заливка base или `emblemFill`, обводка 1.5 px) или круг для сада.
- **Фоны стола** (слой под всем интерфейсом расклада):
  - `glow` — большое радиальное пятно цвета `glow` (центр 36% / 48%, диаметр ~1500) с мерцанием (прозрачность 0.72–1, scale 1–1.03, 6 с) и 14 поднимающихся частиц цвета `accent` (2–3 px, 13–20 с на подъём, разные задержки). Если выключены «Анимации и частицы» — статично и без частиц;
  - фото — `BoxFit.cover`, сверху заливка `bg` с прозрачностью: для тёмных колод `1 − 0.42`, для светлых `1 − 0.38`, плюс затемнение из настроек;
  - `plain` — просто `bg`;
  - `custom` — файл пользователя, как фото.

## 11. Логотип
Векторный, три карты веером: левая и правая — повёрнутые на −14° и +14° прямоугольники 18×26 со скруглением 3, центральная 18×28 с заливкой `bg`, в центре ромб; только обводка `accent`, толщина 3 (при 18 px) / 2 (крупно). Нарисовать `CustomPainter` или SVG в assets. Иконку приложения для Windows (`windows/runner/resources/app_icon.ico`) сгенерировать из него же на фоне `#141517`.

## 12. Доступность
- Все интерактивные элементы — фокусируемые, видимая рамка фокуса 2 px `accent`.
- `Semantics` у карт: «Карта 5, закрыта» / «<название> — выбыла» / «<название> — выбор».
- Контраст текста не ниже 4.5:1 — проверь пары `text`/`muted` на `bg`/`surface` для всех колод и сообщи, если где-то не проходит.
- Цели клика не меньше 36×36 (кнопки 44).

## 14. Тесты (обязательно)
Юнит-тесты на чистую логику:
- `sheet_link`: разные формы ссылок (с `/edit`, `#gid=`, `?gid=`, `/htmlview`, мусор) → ID/gid или `format`;
- `sheet_parser`: русские/английские заголовки, разный регистр и пробелы, лишние столбцы, нет одного/двух столбцов → `columns` со списком, значения «прочитано», пустые строки;
- `layout`: проверочные значения из 8.2 и крайние случаи n = 2 и n = 60 на 1280×720;
- детерминированность авто-цвета.

Виджет-тест: расклад из 5 карт → 4 клика → появляется показ выбора.

## 15. Критерии приёмки
- [ ] Сборка `flutter build windows` без ошибок и предупреждений анализатора.
- [ ] Первый запуск: вставка ссылки на открытую таблицу с правильными столбцами → «Начать расклад» → карты = число непрочитанных.
- [ ] Ошибки `format`, `access`, `columns` воспроизводятся и показывают правильные тексты.
- [ ] Прочитанные книги не попадают в колоду; счётчики в панели верные.
- [ ] Окно 1280×720 … 2560×1440 и любые промежуточные размеры: карты целиком помещаются, ничего не обрезано, панель не наезжает.
- [ ] 2, 12, 40, 60 карт — сетка и шрифты по разделу 8.
- [ ] Все пять колод и семь фонов переключаются в настройках сразу, выбор сохраняется между запусками.
- [ ] Отключение сети: старт из кэша, чип и плашка офлайна; включение сети → «Проверить снова» → плашка «Связь восстановлена», исчезает через 4 с, расклад не сброшен.
- [ ] Горячие клавиши работают; Tab проходит по картам и кнопкам.
- [ ] Размер и позиция окна восстанавливаются после перезапуска.
